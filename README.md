# 截图拼接

把多张截图或一段滚动录屏拼成一张长图的原生 macOS 工具。

## 下载与安装

**[下载 1.0 DMG](https://github.com/Andyshenjx/ScreenshotStitch-Mac/releases/download/v1.0/ScreenshotStitch-1.0-macOS-arm64.dmg)** · [查看最新发布](https://github.com/Andyshenjx/ScreenshotStitch-Mac/releases/latest)

1. 打开 DMG，把「截图拼接」拖到「应用程序」。
2. 打开 App，导入截图或滚动录屏，检查对齐后的预览，再导出 PNG。

安装包适用于 Apple Silicon（M 系列）Mac。App 声明的最低系统版本为 macOS 15。本次发布使用已有的 App 打包，未重新编译或运行验证。安装包未经 Apple 公证。

## 功能

- **截图拼接**：导入多张截图，自动识别重叠区域，可调整图片顺序并重新对齐。
- **录屏转长图**：从滚动录屏中提取画面，按内容对齐并预览拼接结果。
- **PNG 导出**：支持缩放、原始宽度和分段导出。
- **本地历史**：重新打开之前的拼接项目，继续调整或导出。

遇到问题可以通过 [GitHub Issues](https://github.com/Andyshenjx/ScreenshotStitch-Mac/issues) 反馈，并附上 macOS 版本、输入类型和复现步骤。
